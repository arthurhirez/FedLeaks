## Project Structure

```text
FedLeaks/
│
├── backbone/                   # Core algorithms and base classes
├── data/                       # Raw data
├── datasets/                   # Dataset loaders and preparation logic
├── models/                     # Federated Learning models
├── simulation/                 # Simulation scenarios and orchestration
│   └── utils/                  # Helper functions and utilities
│   └── Pipeline_Simulation.py  # Pipeline manager for federated simulation runs
│
├── utils/                      # Helper functions and utilities
│
├── Auto_exp.py                 # Automates experiment workflows
├── Compile_experiments.py      # Generate report data
├── Process_Results.py          # Processes and visualizes outputs
├── Run_Experiment.py           # Launches experiments
│
└── requirements.txt            # Python dependencies
```
